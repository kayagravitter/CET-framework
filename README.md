Welcome to the official repository for the **Creationist Entanglement Theory (CET)** simulation framework. This project serves as an open-source evaluation suite designed to stress-test weak structured signals embedded in intense stochastic noise environments using localized geometric topological constraints.

## 📌 Latest Milestone: v2.1 SNR Optimization
Our latest framework update transitions the evaluation metrics from a global array dilution model to an isolated, controlled environment measurement framework. By localizing our signal and variance analysis strictly within the active boundary topology, we have successfully resolved spatial noise floor artifacts.

* **Baseline Raw SNR:** 0.020653
* **Localized CET Filter SNR:** 0.031341
* **Net Performance Increase:** **+51.7% Gain** in structured field detectability.

The simulation proves mathematically that physical or geometric boundary constraints can successfully shield a high-density core vector field from ambient environmental noise infiltration.

## 🚀 Quick Start & Installation

### Prerequisites
Ensure you have Python 3.8+ and NumPy installed on your machine:
```bash
pip install numpy
```

### Running the Stress Test
Clone the repository and execute the main pipeline simulation script to verify the math locally:
```bash
git clone https://github.com
cd CET-framework
python main.py
```
